Website Update Guide

How to Update Your Website

This guide explains how to make the most common updates to your website — changing the menu, swapping photos, adding events, and more. No technical background needed.

What you need: A basic text editor — Notepad (Windows) or TextEdit (Mac). All your website files are in the bellini-website folder. Every update follows the same pattern: open a file, find the text, change it, save, re-upload to Netlify.

Section 1

Updating the Menu

The menu lives in menu.html. You can change dish names, descriptions, prices, and add or remove items. Open the file in a text editor and look for the comment markers.

1

Open the file

Go into your bellini-website folder → right-click menu.html → Open With → Notepad (Windows) or TextEdit (Mac).

2

Find the dish you want to change

Press Ctrl+F (Windows) or Cmd+F (Mac) to search. Type the dish name — for example "Spaghetti Carbonara" — and it will jump to that part of the file.

3

Change the name, description, or price

Each menu item looks like this — only change the parts highlighted in green:

<!-- MENU ITEM --> <div class="menu-item"> <div class="item-info"> <h4>Spaghetti Carbonara</h4> <p>Egg yolk, guanciale, Pecorino Romano, black pepper</p> </div> <span class="item-price">$13</span> </div>

Change only the text between the tags. Do not delete the tags themselves (<h4>, </h4>, etc.).

4

Add a new dish

Copy an entire menu item block (from <div class="menu-item"> to its closing </div>), paste it below another item in the same category, and change the text.

5

Remove a dish

Find the dish, select everything from <div class="menu-item"> to the matching </div>, and delete it.

✓ After saving, open menu.html in your browser to check it looks right before re-uploading.
Section 2

Swapping Photos

All photos are stored in the images/ folder inside bellini-website. The easiest way to swap a photo is to replace the file with the same filename.

1

The simple way — same filename

Prepare your new photo. Rename it to exactly match the file you want to replace — for example garden-night.jpg. Then drag it into the images/ folder and choose "Replace" when asked. Done.

✓ The website will automatically show the new photo everywhere that image was used.
2

Adding a new photo with a different name

Drop the new photo into the images/ folder. Then open the HTML file where you want to use it, find the image tag, and change the filename:

<img src="images/your-new-photo.jpg" alt="Description of the photo"/>
3

Photo sizes — what works best

Keep photos under 1.5 MB each so the website loads fast. For the hero (homepage full-screen), landscape photos work best. For food shots, square or portrait is fine.

⚠ Do not rename photo files without also updating the HTML — or the image will appear broken on the site.

Section 3

Updating Events

Event information lives in events.html. The most common updates are: announcing the next season dates, adding new event descriptions, and updating the mailing list link.

1

Next season dates (no yearly update needed)

The season badge and announcement text are written to be evergreen — "Concert Season: November – April" and "announced each year around October" — so you don't need to touch these every year. Only update them in events.html and content.json (search for nextSeasonBadge) if the actual concert season months ever change.

2

Add a new past event

Copy one of the existing events-season blocks and paste it below. Change the title, description, and photo filename to match your new event.

3

Update the mailing list link

Search for shorturl.at/NjHwT — replace it with your updated signup link if it changes.

✓ Also update the homepage teaser in index.html — search for "Next season" to find it.
Section 4

Changing Opening Hours

Hours appear in multiple places — the homepage, reservations page, contact page, and footer of every page. Use Find & Replace to update all at once.

1

Use Find & Replace

Open each HTML file in a text editor. Press Ctrl+H (Windows) or Cmd+Option+F (Mac) to open Find & Replace. Search for the current time and replace with the new one.

Find: 10:30 AM – 10:30 PM Replace: 11:00 AM – 11:00 PM
2

Files to update

Run the replacement in: index.html, reservations.html, contact.html, and all footer sections (every page has a footer with hours).

✓ The easiest approach: open each file one by one and do Find & Replace. Takes about 2 minutes total.

Section 6

Activating Google Analytics

Google Analytics shows you how many people visit the website, where they come from, which pages they read most, and more. It's free. The tracking code is already added to every page — you just need to replace the placeholder ID with your real one.

1

Create a Google Analytics account

Go to analytics.google.com and sign in with your Google account (belliniphnompenh@gmail.com). Click "Start measuring," enter Bellini Bistro Italiano as the account name, follow the steps, and select "Web" as your platform. Enter your website URL when asked.

2

Copy your Measurement ID

At the end of setup, Google gives you a Measurement ID — it looks like G-AB12CD34EF. Copy it.

3

Replace the placeholder in all HTML files

Open each HTML file in a text editor. Press Ctrl+H (Find & Replace) and replace G-XXXXXXXXXX with your real ID. Do this in all 7 files.

Find: G-XXXXXXXXXX Replace: G-AB12CD34EF ← your actual ID
4

Re-upload to Netlify

Upload the updated folder to Netlify (see Section 7). Within 24–48 hours, visitor data will start appearing in your Google Analytics dashboard.

✓ Once active, visit analytics.google.com anytime to see how the website is performing.
Section 7

Re-uploading to Netlify After Changes

Every time you update the website files, you need to re-upload the folder to Netlify to make the changes live. It takes about 1 minute.

1

Go to netlify.com and log in

Use the email and password you registered with (belliniphnompenh@gmail.com).

2

Open your site

Click on your Bellini site from the dashboard.

3

Drag and drop the folder

Go to Deploys tab. At the bottom, there is a drag-and-drop area that says "Need to update your site? Drag and drop your site output folder here." Drag your entire bellini-website folder onto that area.

4

Wait ~30 seconds

Netlify processes the upload and your live site is updated. You'll see a green "Published" message when it's done.

✓ Always keep the bellini-website folder on your computer as your master copy. Make changes there first, then upload.
⚠ Always upload the entire bellini-website folder — not just the files you changed. Netlify replaces everything each time.
